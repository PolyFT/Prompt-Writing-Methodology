# 科研场景下面向大模型的 Prompt 编写方法学

本仓库提供一套面向科研写作与正式科研文本的大模型提示词方法。核心目标是：在研究者已经明确事实、数据和学术判断的前提下，通过限定任务、语义来源、结论层级与输出形式，降低模型生成中的概念外推、语义漂移和结论越权风险。

## 适用边界

本方法主要服务于“受控表达”任务，包括论文文字修改、方法学整理、图注编写、项目文本组织和审稿意见回复。其重点是保持原始科学含义并提高表达质量，不替代研究者进行事实核验、机理判断或研究决策。

对于文献检索、研究假设提出、开放式讨论等探索性任务，可使用大模型辅助拓展候选方向，但应另行规定信息来源、证据核验和人工决策流程，不宜直接套用本仓库的封闭式生成约束。

## 方法框架

一个可执行的科研 Prompt 应至少回答五个问题：

| 要素 | 需要明确的内容 | 主要作用 |
| --- | --- | --- |
| 任务场景 | 论文、项目书、图注、审稿回复等 | 确定文本功能 |
| 输入依据 | 原始文本、数据、已确认结论或参考材料 | 锁定语义来源 |
| 操作类型 | 改写、压缩、翻译、组织或核查 | 限定模型动作 |
| 输出要求 | 语言、篇幅、结构、术语和完成状态 | 建立验收标准 |
| 风险边界 | 禁止新增的概念、推断、评价或数据 | 阻断非授权外推 |

简化表达为：

> 科研 Prompt = 任务场景 + 输入依据 + 操作类型 + 输出要求 + 风险边界

## 快速使用

最短工作流程为：先确定任务属于受控表达，再填写统一模板；生成后依据审校清单检查事实、概念、结论、术语和格式；涉及关键科学判断或正式提交的文本，必须由研究者逐项确认。

```text
任务场景：说明文本将用于何处。
输入依据：粘贴原始文本、数据说明或已确认结论。
操作要求：说明需要改写、压缩、组织、翻译或核查的内容。
输出要求：规定语言、结构、篇幅、术语和交付形式。
风险边界：禁止新增事实、概念、机制、评价或无来源引文。
```

## 使用原则

- 大模型承担语言与结构辅助，研究者承担科学判断与学术责任。
- 模型输出不能替代原始数据、可靠文献和人工核验。
- 未提供可靠来源时，不生成具体数据、文献、DOI 或实验事实。
- 现象、相关性、因果关系和作用机制应保持原有结论层级。
- 正式文本应保留术语、数字、单位、变量名和引文编号的一致性。

## 维护说明

本仓库面向科研实践持续更新。方法调整应以实际任务中的可控性、可核查性和可复用性为依据，避免把平台特性或单一模型表现写成普遍规则。
